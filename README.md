# AI Video Making Tools Archive Indonesia

Kumpulan proyek **open-source** yang berkaitan dengan pembuatan, penyuntingan, pemrosesan, dan otomatisasi media menggunakan AI.

Repository ini dibuat untuk membantu pengguna Indonesia menemukan proyek-proyek menarik yang mungkin sulit ditemukan atau dipahami karena sebagian besar dokumentasinya menggunakan Bahasa Inggris.

> **Temukan proyeknya di sini. Pahami secara singkat. Lalu kunjungi repository aslinya.**

---

## Tentang Repository

**AI Video Making Tools Archive Indonesia** adalah arsip dan kurasi sederhana untuk berbagai proyek open-source yang berhubungan dengan AI, audio, video, dan pembuatan konten.

Setiap proyek yang tercantum di sini memiliki halaman informasi tersendiri yang berisi ringkasan singkat dalam **Bahasa Indonesia**, kategori proyek, pembuatnya, serta tautan menuju sumber aslinya.

Repository ini **bukan salinan dari proyek-proyek tersebut**.

Saya tidak mengambil, menyalin, atau mendistribusikan ulang kode dari repository yang dikurasi. Proyek, kode, aset, dokumentasi, dan lisensi tetap menjadi milik masing-masing pembuatnya.

Tujuan repository ini hanya untuk:

* menemukan proyek open-source yang menarik;
* memberikan penjelasan singkat dalam Bahasa Indonesia;
* membantu proyek-proyek tersebut ditemukan oleh lebih banyak pengguna Indonesia;
* mengarahkan pengguna ke repository dan dokumentasi aslinya.
